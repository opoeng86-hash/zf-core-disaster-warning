# ZF-Core Disaster Warning

Aplikasi pemantauan dan mitigasi bencana real-time berbasis Flutter dengan kerangka teoretis **Zuhri Formalism**.

## Arsitek & Pencipta Sistem
* **Nama:** Opung Sirr (Abdul Gofur)

## Fitur Utama
* Pemantauan data langsung (*Live API*) dari USGS untuk aktivitas seismik global.
* Pusat komunikasi dan konsultasi interaktif berbasis kecerdasan buatan untuk analisis wilayah (seperti Cipinang Muara).
* Kalkulasi presisi mitigasi bencana (Gunung Meletus, Banjir, Badai, dan Gempa Bumi) menggunakan rumus Zuhri Formalism.

## Cara Menjalankan
Kode sumber utama terletak pada file `main.dart` dan dapat diuji coba langsung menggunakan editor online seperti DartPad.
